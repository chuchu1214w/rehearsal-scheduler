# Season 手机 UI 草图

双击 `index.html`，选择管理员端或成员端。也可以分别打开 `管理员端.html` 和 `成员端.html`。

- 管理员端：七步工作台、四步新建向导、人员与邀请、曲目与排练方案、特殊排程要求、填报进度、排程检查与诊断、排练表版本与发布。
- 成员端：待办首页、三态空闲时间填报、个人排练表、日历订阅入口、账号、登录与邀请。
- 手机界面外的下拉菜单用于快速预览页面或不同状态。

这是已确认的 UI 交互草图。数据、排程、发布、注册、邀请、账号操作与通知均为本地演示，不连接项目后端。

依据：交互设计 v0.2、开发文档及 `design/tokens.css` 的 Season 视觉规范。桌面浏览器同样按手机宽度展示。
