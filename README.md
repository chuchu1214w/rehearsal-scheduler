# 舞团排练排程系统(rehearsal-scheduler)

为舞团路演安排多首曲目排练的排程工具:成员在线填写空闲时间,管理员一键求解(OR-Tools CP-SAT 分层优化),无解时给出诊断与最小调整建议;支持手动微调、锁定重排、版本对比和日历订阅。

**当前状态:需求与设计阶段,尚未开始开发。**
